# Здравница AI — Demo Product
## Роадмап разработки в Cursor

---

## Стек (единый с `.cursorrules`)

- **Frontend:** Next.js (App Router) + TypeScript
- **UI:** Tailwind CSS + Radix UI (shadcn-style) + Lucide React + Framer Motion
- **Формы/валидация:** React Hook Form + Zod
- **Состояние:** Zustand
- **AI-шлюз:** OpenRouter (`https://openrouter.ai/api/v1`)
- **LLM:** `anthropic/claude-sonnet-4-5`
- **Аудио → текст:** `openai/whisper-1` через OpenRouter
- **PDF:** jsPDF (на клиенте в Next)
- **Уведомления:** n8n webhook → Telegram
- **Хостинг для демо:** Vercel (`vercel dev` локально, `vercel --prod` деплой)

## Секция 1 — Герой + Перехват

### Визуал

- Тёмный фон, крупный заголовок по центру
- Подзаголовок: «Система автоматизации входящих заявок»
- Форма по центру на карточке

### Форма

```
┌──────────────────────────────┐
│  Оставить заявку             │
│  ──────────────────────────  │
│  Имя: [________________]     │
│  Телефон: [____________]     │
│  Ситуация: [            ]    │
│            [            ]    │
│  [  Отправить заявку →  ]    │
└──────────────────────────────┘
```

### Канон: что происходит после отправки (перехват)

1. На кнопке — состояние загрузки («готовим ответ и заявку»), идут запросы к `/api/chat` (intercept) и `/api/intercept-notify`.
2. Лид сохраняется в Supabase (`intercept_leads_demo`), в n8n уходит webhook с данными формы и `lead_id`.
3. При успехе (HTTP 200) пользователь **сразу** перенаправляется в Telegram-бота: `?start=<lead_id>`.
4. **Бот, сообщение 1:** привет по имени, отсылка к тексту «ситуация», тёплый тон, один мягкий следующий шаг; без ожидания PDF.
5. **Бот, сообщение 2 (когда готов PDF):** «материал готов» + ссылка/файл; формулировки как **ориентир для разговора со специалистом**, не диагноз и не лечение.
6. Параллельно n8n шлёт **менеджеру** уведомление о новой заявке (как в первом workflow).

Подробная спецификация: `docs/architecture.md` → раздел **Intercept — канон сценария**.

### Промпт для агента (Мила — перехват)

```
Ты Мила — консультант центра Здравница.
Человек только что оставил заявку на сайте.
Ответь тепло и коротко — 3-4 предложения.
Уточни один ключевой вопрос по ситуации.
В конце скажи что готовы помочь прямо сейчас.
Никаких медицинских диагнозов и советов.
Тон: живой, человеческий, без канцелярита.
```

## n8n — два вебхука

### Вебхук 1 — Перехват

**Триггер:** POST с данными формы + ответом агента

**Действия:**
1. Форматировать сообщение
2. Отправить в Telegram

```
Сообщение в Telegram:

🔔 Новая заявка — Здравница

👤 {{ $json.name }}
📞 {{ $json.phone }}
💬 {{ $json.situation }}

🤖 Мила ответила:
{{ $json.agent_reply }}

🕐 {{ $now }}
```

### Вебхук 2 — Протоколист

**Триггер:** POST с номером телефона + PDF (base64)

**Действия:**
1. Декодировать PDF
2. Отправить файл в WhatsApp/Telegram на указанный номер

## Важные детали

**По конфиденциальности:**
Демо не хранит никаких данных. Всё в памяти браузера, после закрытия — ничего не остаётся.

**По промптам:**
Никаких медицинских советов и диагнозов. Мила всегда переводит на врача при малейшей неопределённости.

**По аудио для демо:**
Заготовить тестовый mp3 заранее — 2-3 минуты разговора менеджера с условным пациентом. Реальный сценарий: вывод из запоя, первичная консультация.
